# Phase 5 local completion checklist

Scope: manual parts preparation, prerequisite evidence, live readiness, deterministic ranking and manager-approved assignment. AWS remains explicitly deferred.

- [x] Catalog parts and branch/van stock locations, with tenant-safe relationships.
- [x] SUSPECTED/REQUIRED/NOT_NEEDED requirements, decimal quantities and reasoned changes.
- [x] Append-only confirmations bound to requirement and visit revisions.
- [x] Owner freshness policy with a 24-hour default and 1–168-hour bounds.
- [x] Mandatory safety/access checks with attributed, visit-bound evidence.
- [x] PASS/FAIL/UNKNOWN checks, blockers/warnings and explicit warning acknowledgments.
- [x] READY invalidation on material edits and live rechecking at approval.
- [x] dispatch-v2 skill/workload/familiarity features, explanations and deterministic ties.
- [x] Idempotent approval, current authorization/eligibility and overlap protection.
- [x] Atomic reservation, assignment, snapshots, job event, audit, pending outbox and retry record.
- [x] Production/Docker builds, type checks and lint passed; 28 unit/protocol tests and 50 PostgreSQL integration tests passed; production dependency audit reported no known vulnerabilities.
- [x] All 11 full-Docker real-provider browser scenarios and smoke checks passed, including committed-response interruption and idempotent retry; desktop and 390px mobile screenshots visually reviewed.
- [ ] Successful GitHub CI evidence recorded.

Parts reservations/accounting, external outbox delivery, technician execution/closure, cancellation/rescheduling, production operations and AWS are outside this phase. See the [walkthrough](../operations/phase-5-local.md) and [design](../architecture/0005-readiness-and-assignment.md).
